# Hematology & Immunology Learning Lab

A static GitHub Pages learning application for the Hematoimunologi practical session in Biochemistry Biomedical 3.

## Modules
- Antigen–antibody interaction and agglutination
- ABO blood grouping interpretation (Anti-A, Anti-B, Anti-AB)
- Rhesus (Rh) overview
- ESR/LED principles and Westergren procedure
- Interactive ABO pattern simulator
- LED reading exercise
- Ten-item True/False post-test with automated scoring and explanations

## Deployment
The application is intended for:
https://bnjid.github.io/app.hematobiochemistry/

In GitHub, open **Settings → Pages** and ensure the source is **Deploy from a branch**, branch **main**, folder **/(root)**. The site is static and requires no build step.
